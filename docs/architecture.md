# معماری فنی Qeymatban

این سند تصمیم‌های فنی تأییدشده برای فاز اول پروژه را ثبت می‌کند.

## نمای کلی

```
Next.js (پنل/فرانت)  →  FastAPI (Python, API + مدل ارزش‌گذاری)  →  PostgreSQL + PostGIS
```

## بک‌اند و مدل ارزش‌گذاری — Python / FastAPI

هسته محصول «توضیح‌پذیری قیمت» است، پس این بخش مهم‌ترین لایه پروژه است:

| مؤلفه | ابزار | نقش |
|---|---|---|
| مدل قیمت پایه | XGBoost / LightGBM | پیش‌بینی قیمت روی داده تابولار (متراژ، سن بنا، طبقه، محله، ...) |
| فایل‌های مشابه (comparables) | Embeddings + Nearest Neighbor | یافتن نزدیک‌ترین فایل‌های واقعی به ملک هدف برای مقایسه |
| بازه عدم قطعیت | Quantile Regression یا Conformal Prediction | تولید بازه قیمت به‌جای یک عدد قطعی |
| تفسیرپذیری | SHAP | توضیح سهم هر ویژگی (نور، طبقه، ویو، پارکینگ و...) در قیمت نهایی |
| API سرویس‌دهی | FastAPI | serving مدل + endpoint های B2B/SaaS و API مالی |

## فرانت‌اند — Next.js

داشبورد دفاتر املاک و پلتفرم‌های آگهی: نمایش بازه قیمت، فایل‌های مشابه، نمودار سهم ویژگی‌ها. پشتیبانی کامل RTL/فارسی.

## دیتابیس — PostgreSQL + PostGIS

داده ساختاریافته ملک، معامله و ویژگی‌ها در PostgreSQL؛ پسوند PostGIS برای پرس‌وجوهای جغرافیایی (محله، خیابان، فاصله تا نقاط مرجع) که ورودی مستقیم مدل ارزش‌گذاری هستند.
